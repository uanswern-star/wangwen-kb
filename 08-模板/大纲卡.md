# 大纲卡（全书级，动笔前填）

> 来源：库内 `技巧-大纲设计` + 2026-08-13 联网核实（番茄签约需 2 万字正文+完整大纲；新人首本 80-150 万字；前 10 万字是推荐关键）

---

## 0. 一句话梗概（30 字内，写不清=卖点没想明白）

> 主角 + 目标 + 阻碍 + 代价/卖点，如："夜班司机冷婧接了趟鬼出租，每单一个都市执念，收完梦发现自己的梦也被收走了。"

## 1. 市场定位

| 项 | 填 |
|---|---|
| 题材/分类 | （如：都市日常 / 悬疑灵异 / 系统流） |
| 核心卖点 | （读者看这本书图个啥：碾压爽点/烟火气/单元剧……挑 1 个拉满） |
| 对标作品 | （同赛道活样本 2-3 本 + 它们的过人处） |
| 预计篇幅 | （新人 80-150 万，防烂尾） |

## 2. 基础设定（每条一句话）

- 主角档案：出身 / 金手指 / 性格 / 目标
- 反派/对立面：谁挡路，他的执念是什么
- 核心冲突：主角要什么 vs 什么不让他得到
- 结局方向（提前定，避免烂尾）：圆满 / 悲壮 / 开放式

## 3. 三层大纲

**主干（起承转合或三幕）**：开端（1-10 章入题+立人设+亮金手指）→ 发展（升级+波折+支线）→ 高潮（决战+反转+伏笔回收）→ 结局（收尾点题）。

**分卷表**（每卷一个小目标+小反派+小高潮）：

| 卷 | 章节范围 | 卷目标 | 卷末爆点 | 主线推进（% 进度） |
|---|---|---|---|---|
| 卷一 | 1-30 | | | |
| 卷二 | 31-70 | | | |
| 卷三 | 71-120 | | | |

**爽点排布**：在分卷表标出大爽点位置（每卷 1-2 个），避免扎堆或空窗；卷末必有一个爆点或大钩子。

## 4. 三线并行表（番茄爆款通用逻辑：一条主线拉满+两条副线穿插）

| 线 | 内容 | 每 N 章必须推进一次 |
|---|---|---|
| 主线 | 主角终极目标 | 每章 |
| 副线 A（感情/搭档） | | 每 3 章 |
| 暗线（伏笔/阴谋） | | 每 5 章 |

## 5. 伏笔登记表（必填，防"埋了忘收"）

| 伏笔 | 埋设章节 | 内容 | 计划回收章节 |
|---|---|---|---|
| | | | |

## 6. 常见误区（对照自查）

- 大纲细到每章 → 写太满反而写不动（大纲只写承诺，细节留白）
- 只排爽点不排转折 → 高开低走
- 大纲写完从不回头看 → 大纲是活文档，开卷前必回顾、跑偏先改大纲再写
