# 章节自检卡（写完每章、发稿前 5 分钟过一遍）

> 来源：库内 `技巧-断章卡点`/`概念-钩子`/`概念-爽点` + 2026-08-13 联网核实（番茄追读标准）

---

## 每章三问（核心，答不出就改）

1. **钩子留没留**：结尾 200 字有没有新危机/新悬念/新误会？没有 → 读者划走 → 重写结尾
2. **爽点够不够**：本章有没有一个"满足感时刻"（打脸/收获/进展/温情）？没有 → 加或调整节奏
3. **剧情推没推**：本章推进了主线/副线/暗线哪一步？三线都原地踏步 → 删或合并

## 番茄硬指标（量化自查）

- [ ] 章节字数 2000-2500（番茄单章标准）
- [ ] 前 500 字入题：承接上章钩子，没有铺垫废话
- [ ] 中段有情绪压低（矛盾/危机），不是平铺直叙
- [ ] 结尾 200 字有钩子（对照 `技巧-断章卡点`）
- [ ] 全章有至少一个"可记忆点"（名场面/金句/反转，读者能记住）

## 三线推进检查（每章勾一次）

- [ ] 主线有进展（哪怕一小步）
- [ ] 副线（感情/搭档）最近 3 章内动过
- [ ] 暗线（伏笔/阴谋）最近 5 章内动过，且所有埋设的坑都登记在案（对照大纲卡伏笔表）

## 防水文检查（高频翻车点）

- [ ] 没有纯过渡灌水章（可合并就合并）
- [ ] 对话没有全场聊废话（对照 `技巧-市井对话写法`）
- [ ] 笑点没有为凑而凑（对照 `技巧-搞笑对白节拍`）

三问 + 钩子句是否成立 + 字数达标 → 发。
