# 模板库

新建条目时，复制对应模板到目标分类目录，填空即用。

## 通用骨架（所有条目都遵守）

```markdown
# 标题

---

正文（含分类专属字段）

**使用情况**：灵感 / 待用 / 已用
**Tags**：#题材 #类型 #状态 #格式
**来源**：（可选）出处
```

字段顺序铁律：**正文主体 → 使用情况 → Tags → 来源**。创作内容永远在前，管理信息在后。

## 命名规范

条目文件：`[分类]-[名称].md`，例如 `世界观-功德法修炼体系.md`。

## 新增条目流程

1. 打开对应模板复制全文
2. 粘贴到目标分类目录的新文件（按命名规范起名）
3. 填空，删掉不需要的字段行
4. 打标签（题材 / 类型 / 状态 / 格式 四类）
5. 在 `01-索引/总索引.md` 登记一行
