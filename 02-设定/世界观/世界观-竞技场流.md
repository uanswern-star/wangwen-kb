# 竞技场流

---

**类型**：玄幻 / 都市异能 / 游戏异界
**力量体系**：战力与竞技规则强绑定——积分天梯/段位排名决定资源分配；连胜奖励、越级挑战加成；战力可量化（系统面板/战意波谱）；强者靠"打比赛"而非闷头修炼升级（升级流变体：竞技升级流）
**地理**：竞技场核心空间（跨位面擂台、悬浮擂台群、压缩空间内千擂并行）；分战区/分擂层级（入门 → 百强 → 天骄榜 → 诸天）
**历史**：擂台上古存在/强者意志筛选继承者（中期真相线）；从民间擂台演变为世界规则（制度演化史）
**阵营势力**：主办方（系统/宗门/天神，定规则与结算）、选手（角斗士/天骄/平民黑马）、博彩盘口、观众资本；竞技场外的宗族/军阀借竞技场争夺话语权
**特色规则**：
- 普通战"只分高下不定生死"，可开生死局（双方同意，赌注翻倍）
- 匿名代号制：擂台身份可遮蔽真实身份（平民借竞技场晋升、规避家族追杀——"Player"式双重身份）
- 直播+下注：赛前限时下注，赔率随下注人数浮动（"台上是赌狗，台下也是赌狗"）
- 挑战赛邀约制：天梯前 N 名或受邀约才能进高阶擂台；胜负影响声望与积分
