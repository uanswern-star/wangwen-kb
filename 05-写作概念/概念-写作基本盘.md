# 写作基本盘

---

**定义**：网文写作者能力模型中的"入场券"——阅读量 + 文字功底是硬门槛，写作能力非常吃时间积累、且"少年时才能成长"（灵感/手感/表达欲的黄金期）。观点源自知乎高赞（流浪的蛤蟆，1216 赞）。

**例子**：资深作者自述——早期大量阅读建立语感与套路库，写作多年后仍承认"基本功是在前几年吃出来的"，后期补课成本远高于早期积累。

**拆解**：
- 阅读量 = 输入盘：套路、语感、读者心理都在"读"里，输入不足则输出无源
- 文字功底 = 表达盘：把脑内画面转成文字的肌肉记忆，靠写量堆出来
- 时间性 = 不可逆盘：少年期表达欲与学习能力最强，错过黄金期事倍功半
- 推论：与其焦虑"天赋"，不如把基本盘当长期主义经营——读 + 写 + 趁早

**应用场景**：新人作者自我评估（缺哪块补哪块）、产能规划（固定阅读/写作配额）、心态建设（写作是慢变量，不速成）。
