# 语录-市井语录场景词表（按场景查表取词）

---

**用途**：写市井/底层角色对白时**按场景查表取词**，一句话里点缀 1-2 个词就够了（技巧-市井对话写法：方言点缀法——只点缀关键字词，不整句方言，一页 ≤2 个口头语防油腻）。红线：脏话一律**和谐化**（谐音/委婉/软脏话），全站无硬脏字。

## 一、底层/擂台（糙话·和谐版）

> 黑拳场、斗兽场、底层选手互怼用。狠、短、带节奏，但字面干净。

| 词/句 | 场景 | 用法示例 |
|---|---|---|
| 你瞅啥？/瞅你咋地 | 挑衅开场 | 对手瞪冷婧："你瞅啥？" |
| 信不信我削你 | 威胁 | 疤哥的人："信不信我削你。" |
| 完犊子 / 滚犊子 / 扯犊子 | 废物/滚蛋/胡扯 | "就这？完犊子玩意儿。" |
| 哪儿凉快哪儿待着去 | 赶人 | 擂主赶挑战者 |
| 别膈应人了 | 恶心/烦 | 对油腻对手 |
| 给你能耐完了 | 藐视 | "唉我去，给你能耐完了。" |
| 装什么犊子 | 嘲讽装逼 | 对摆谱反派 |
| 皮痒了是吧 | 欠揍 | 轻威胁 |
| 我儿曹植（=我操和谐版） | 感叹 | 惊讶时脱口而出 |
| 往那一站就是全家福（=全家死光和谐版） | 毒舌 | "你往那一站，就是全家福。" |
| 退出生物圈吧，好吗？（=去死和谐版） | 狠话 | 碾压前放话 |

## 二、市井语（通用口头禅·全民可懂）

> 任何市井场景通用，不挑地域。作用是"说人话"的底色词。

| 词/句 | 含义 | 用法示例 |
|---|---|---|
| 得嘞 / 好嘞 | 收到/同意 | 摊主接单："得嘞，您稍等。" |
| 那可不 | 就是啊/当然 | 附和："那可不，饿着肚子怎么打。" |
| 好家伙 | 感叹 | "好家伙，这丫头饿的时候贼猛。" |
| 得亏 / 亏得 | 幸好 | "得亏跑得快，命和饭都保住了。" |
| 雀食（=确实） | 认同 | 冷婧："雀食。" |
| 整明白没 / 整岔劈了 | 搞定没/搞错了 | "账整明白没？" |
| 走着瞧 / 你等着 | 威胁（轻量） | 撂话用 |
| 搭白算数 | 说话算话 | 市井交易："搭白算数，一碗面换一顿架。" |
| 划得来 / 不划算 | 值不值 | 算账逻辑："这顿架划得来。" |
| 磨叽 / 磨洋工 | 拖延/混 | 催人："别磨叽了。" |

## 三、方言点缀（全国可猜·挑字眼用）

> 每句只用 1 个词，读者能猜出意思即可，不整句方言。

| 词/句 | 方言区 | 含义 | 用法示例 |
|---|---|---|---|
| 搞么斯 | 湖北 | 干什么 | "你搁这儿搞么斯？" |
| 信了你的邪 | 湖北 | 服了你了（无奈） | "信了你的邪，还有这种人。" |
| 巴适 / 要得 | 四川 | 舒服/行 | 厨尸长："这面，巴适。" |
| 哦豁 / 遭了 | 四川/重庆 | 糟了 | "哦豁，钱被场子抽走了。" |
| 中不中 | 河南 | 行不行 | "中不中？说个话。" |
| 嘎哈 | 东北 | 干什么 | "你嘎哈呢？" |
| 甭（介） | 北京 | 不用 | "甭跟他废话。" |
| 俺滴乖乖来 | 安徽 | 我的天 | 围观："俺滴乖乖来，饿成这样还能打？" |
| 么么三 | 云南 | 我的天 | 惊叹 |
| 灵醒 | 湖北 | 干净漂亮 | 夸人："这丫头长得灵醒。" |
| 扎实 | 湖北 | 厉害/分量足 | "这一拳打得扎实。" |
| 得劲 | 河南/东北 | 舒服 | "这碗汤饼下肚，得劲。" |

## 四、糙话损人（不带脏·比喻流）

> 损人不吐脏字，靠比喻/歇后语/反话。适合配角互损、嘴炮王解说、摊贩斗嘴。

| 词/句 | 含义 | 用法示例 |
|---|---|---|
| 你算哪根葱 | 你算老几 | "你算哪根葱？也配站这上面？" |
| 装蒜 | 装模作样 | "别跟我装蒜了。" |
| 面（太面） | 懦弱没本事 | "他太面了，一拳都接不住。" |
| 碴子 | 不好惹/厉害 | "黑拳场谁都不敢惹他，他是碴子。" |
| 老黄瓜刷绿漆——装嫩 | 装嫩 | 说老选手 |
| 铁公鸡——一毛不拔 | 抠门 | 说疤哥抽成 |
| 棒槌 / 二把刀 | 外行/手艺差 | "你这就是二把刀水平。" |
| 点背不能赖社会，命苦不能怪政府 | 自嘲倒霉 | "点背不能赖社会，输了怪自己饿。" |
| 干啥啥不行，干饭第一名 | 只会吃 | 反向夸冷婧（绝配饿货人设） |
| 三脚踹不出一个屁 | 闷葫芦 | 说冷婧话少 |
| 年轻真好，倒头就睡 / 婴儿般的睡眠 | 调侃昏睡/睡得好的人（围观损话·暴力消解） | 打晕对手后围观者："胳膊折了，婴儿版，年轻真好。"（用户自产，2026-08-15 第1章已用） |

## 五、软脏话（阴阳·现代网感）

> 表面礼貌字面干净，实际杀伤力拉满。适合反派阴阳、稽查员较真、解说员吐槽。

| 词/句 | 潜台词 | 用法示例 |
|---|---|---|
| 哦 / 嗯 / 都行（冷暴力三件套） | 你死了 | 冷婧对疤哥："哦。"（人设自带） |
| 你好棒哦 / 你好厉害哦 | 你算个屁 | 反派阴阳冷婧 |
| 那我不打扰你了 | 你可以滚了 | 白账查账后告辞 |
| 你开心就好 | 关我屁事 | 冷婧终结对话 |
| 你可真是我的犬系好友（=你真狗） | 你真狗 | 嘴炮王吐槽 |
| 你多冒昧啊 | 你不礼貌 | 对越界反派 |
| 给你颁个诺贝尔一直讲（=你说太多了） | 闭嘴吧 | 解说员嫌话多 |
| 你是活爹（=无语） | 服了你了 | "你可真是活爹。" |

## 六、摊贩叫卖（烟火气·食材/盘口通用）

| 词/句 | 场景 | 用法示例 |
|---|---|---|
| 走过路过别错过 | 叫卖 | 厨尸长摊车 |
| 最后三碗，卖完收摊 | 饥饿营销 | 厨尸长："最后三碗，卖完收摊。" |
| 童叟无欺，假一赔十 | 保真 | 摊贩自证 |
| 不甜不要钱 / NoSweetNoMoney | 水果摊→万物 | 已有独立卡 `热梗-NoSweetNoMoney市井英语` |
| 多拿点，给你抹个零 | 算账式拉客 | "三块五，多拿点给你抹个零。" |

## 使用规则（与技巧-市井对话写法联动）

1. **一页 ≤2 个口头语**，多了油腻；方言只点缀 1 个字眼，整句方言劝退读者。
2. **按角色分层取词**：底层选手取第一节（糙话和谐版）、市井配角取第二节（通用口头禅）+ 第三节（方言点缀）、反派/稽查取第五节（软脏话阴阳）、摊贩取第六节。
3. **人设绑定**：口头禅要能变形、承载态度（技巧卡第二条），冷婧用"哦/嗯"（软脏话三件套天然适配冷幽默底盘）、厨尸长用"巴适/得劲/信了你的邪"（死人感+烟火气）、嘴炮王用"干啥啥不行干饭第一名"（解说位）。
4. **脏话红线**：全站无硬脏字，一律走第一节/第五节和谐版；文风卡红线"低俗/生造禁入"优先。
