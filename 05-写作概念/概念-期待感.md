# 期待感

---

**定义**：读者对"将要发生的好事或大事"的预知与等待心理。相比爽点的即时满足，期待感是延迟满足，是更高级、更持久的追更动力。

**例子**：升级流里的"即将突破"提示、隐藏身份"即将曝光"的倒计时、《赘婿》宁毅布局多年"即将收网"的压迫感。

**拆解**：
- 期待感公式：明确目标 + 可见进度条 + 悬念倒计时
- 三种常见期待：实力提升期待（还差一步升级）、身份揭秘期待（马甲何时暴露）、计划收网期待（布局何时引爆）
- 与爽点的关系：期待感负责吊住读者，兑现那一刻引爆爽点；高段位作者用"期待感拉满 → 爽点兑现"循环驱动整本书
- 反例：永远兑现不了的期待会消耗信任，读者弃书

**应用场景**：
- 每卷设立一个大期待（如"一年后秘境开启""三年之约"），每章有小的进度推进
- 用旁白、配角对话、系统面板反复提醒倒计时，强化紧迫感
- 小期待快速兑现建立信任，大期待缓慢推进保持悬念
