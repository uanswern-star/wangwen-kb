# 概念-单元剧结构

---

## 一句话

**单元剧 = 主线推进 + 每 N 章一个完整小故事**：单集有起承转合、可随时入坑，主线靠单元里的人物与伏笔悄悄生长——市井流和免费阅读平台的最佳骨架。

## 为什么成立

1. **单集完整 → 随时入坑**：番茄等免费平台读者随意点开一章，单元剧保证"随便点开哪章都像看了个完整短篇"，留存门槛最低。
2. **追读稳 → 钩子密度天然高**：每个单元结尾都要留"下集预告"，等于每 N 章强制一次追读钩子，比单线长故事更容易维持追读率（对照 `概念-钩子`）。
3. **认知负担低 → 读者不累**：不用记复杂主线，单元间独立，适合通勤碎片阅读——市井流、日常流的天然匹配。
4. **写作压力小 → 卡文概率低**：单单元独立构思，一个单元写崩不拖垮全书。

## 单元模板（一个单元的标准骨架）

```
① 事件引入（一个市井小事件/一个乘客/一笔生意）
② 小冲突（利益/误会/习惯碰撞——靠算账逻辑驱动）
③ 反转或温情（真相揭开/人情回馈/意外收获）
④ 收尾点题（单元主题一句话落点，别硬升华）
⑤ 主线线索 +1（伏笔登记：单元里某人/某事指主线）
```

单集篇幅参考：3-5 章 / 单元，市井流取短（2-3 章），副本类取长。

## 主线如何穿插（单元剧翻车点=主线消失）

- **单元是主线的切片**：每个单元的人物、事件、收获都要指向主线 5% 以上——主角的人情网、舞台的势力变化、一个反复出现的神秘乘客。
- **伏笔登记**：用 `技巧-伏笔与回收` 的登记表，单元内埋的线必须列进总伏笔表，否则必忘。
- **节奏推进**：每 5-10 个单元安排一次主线大推进（大人物登场/舞台升级/身世揭开），防止"单元剧=流水账"。
- **单元递进**：单元不能只重复套路，同类型单元要升级（第1个温情单元→第5个温情单元要带反转）。

## 注意（三个常见病）

1. **单元同质化**：每个单元换壳不换核 → 每 3 个单元换一种单元类型（温情/搞笑/悬疑/冲突轮换）。
2. **主线隐身**：连续 10 个单元主线没动 → 读者弃书。给主线设"倒计时钩子"（如：那个神秘乘客每 3 个单元出现一次）。
3. **单元收尾拖沓**：单元结束后的"点题"最长 1 段，长了就是说教（对照 `概念-黑色幽默` 的反说教原则）。

## 联动卡

- `概念-无限流副本`：副本结构=单元剧的强规则版，副本间可插入现实单元做节奏缓冲。
- `概念-市井流`：市井流默认推荐单元剧骨架，固定舞台+固定配角=天然单元工厂。
- `技巧-断章卡点`：单元结尾即章末，钩子写法直接用。

## 应用到《深夜钢筋》

- 骨架：每单乘客=一个单元（深夜百态轮换：温情单/搞笑单/悬疑单），主线=鬼出租收梦的秘密+何戳电台线
- 节奏：每 3 单元插入一次主线推进（收梦者身份线索/建材市场老板的暗线）
- 反例自查：连续两个单元套路相同 → 停写，换单元类型
