# 语录-江湖切口与盘口黑话（黑拳场/赌局生态用）

---

**用途**：写黑拳场、盘口区、赌局（千面赌徒/庄九）、万界擂台生态对白时取词。**红线**：与市井词表卡同——脏话一律和谐化；一页 ≤2 个黑话词（黑话当点缀不当主菜）；读者看不懂的词不硬用（选语义可猜的）。

## 一、江湖切口（黑拳场/老江湖互认·选语义可猜的用）

> 出自江湖隐语/旧时切口，挑"读者能凭字面猜出七分"的入书，生僻的只作氛围点缀。

| 词/句 | 出处 | 含义 | 用法示例 |
|---|---|---|---|
| 海底 | 江湖隐语 | 背景/势力/靠山 | "他海底深，别惹。" |
| 合吾 | 江湖隐语 | 同党/自己人 | 对暗号："合吾？""合吾。" |
| 挂票眼 | 江湖隐语 | 欠账 | "这顿面先挂票眼，回头还。" |
| 挑偏子 | 江湖隐语 | 分钱 | "赢的赏金，哥几个挑偏子。" |
| 识相 | 江湖隐语 | 懂江湖规矩 | "识相点，让出擂台。" |
| 门子 | 江湖隐语 | 机关/门道 | "这黑拳场有门子，水深。" |
| 洋盘 | 江湖隐语 | 不懂行的外人 | "一看就是洋盘，连规矩都不懂。" |
| 捞偏门 | 江湖隐语 | 走歪门邪道赚钱 | "他不打正赛，专捞偏门。" |

## 二、赌局/盘口黑话（庄九/青眼/千面赌徒/下注群众用）

> 万界盘口生态专用——**和谐化处理**：不写真实博彩术语（通杀/抽水等原词慎用），改写"场子/盘子/庄家"语义。

| 词/句 | 出处 | 含义 | 用法示例 |
|---|---|---|---|
| 场子/盘子 | 博彩隐语演化 | 赌场/盘口生意 | "这是我的盘子。"（庄九经典） |
| 庄家 | 通用 | 定赔率的人 | "庄家说了算。" |
| 下注/押 | 通用 | 投注 | "压她，饿的时候贼猛。" |
| 赔率 | 通用 | 赢钱比例 | "赔率还在涨。" |
| 追注/加注 | 台湾赌场用语 | 连赢时继续加注 | "连赢三场，庄家开始追注了。" |
| 路单/路子 | 赌场用语 | 记录每局结果分析趋势 | "盘口那边路子都记着呢。" |
| 杀码 | 澳门赌场用语 | 经理删除不利赌注 | "盘口杀码，这场不算。" |
| 中宝/中咗宝 | 粤语赌场用语 | 买中了/赌赢了 | "中了宝了，压冷门赚翻了。" |
| 走宝 | 粤语赌场用语 | 错过赢钱机会 | "没压她，走宝了。" |
| 磨烂蓆 | 粤语赌场用语 | 沉迷赌桌磨到输光 | "别磨烂蓆，见好就收。" |
| 辣著 | 粤语赌场用语 | 因小失大输掉大量 | "输了还上头，辣著了。" |
| 陀地 | 粤语赌场用语 | 本地地头蛇 | "场子是陀地罩的。" |
| 迫杀 | 粤语赌场用语 | 怎么下都输 | "这场迫杀，别进了。" |
| 打老虎 | 粤语赌场用语 | 冲大奖 | "盘口开大奖，都想打老虎。" |
| 泥码/现金码 | 澳门赌场用语 | 不能兑现的筹码/可兑现筹码 | "发的是泥码，花不出去。" |
| 叠码仔 | 澳门赌场用语 | 代客投注赚佣金的人 | "叠码仔闻着味就来了。" |

## 使用规则（与市井词表卡/技巧卡联动）

1. **黑话当点缀**：一页 ≤2 个黑话词，读者能猜出意思才用；生僻切口（青子/钢口/挑偏子）只给老江湖互认场景，一次最多 1 个。
2. **按角色分层**：疤哥/黑拳场老油子用第一节（江湖切口）；庄九/青眼/千面赌徒用第二节（盘口黑话）；嘴炮王/解说位用第三节（方言狠话+歇后语）。
3. **谐音/和谐红线**：全站无硬脏字；粤语"冚家铲"、川渝"哈麻批"等硬脏词不入书；"辣著/磨烂蓆"等需读者可猜才用。
4. **世界观缝合**：盘口黑话可直接嫁接万界设定（"泥码"→"种子盲盒码"、"路子"→"擂台积分路单"），黑话本身就是世界观的烟火气。
