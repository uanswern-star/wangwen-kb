# 语录-男人花期短人生错位

---

**金句**：「年轻有贼心没贼胆（穷），年壮有贼胆没贼心（忙），心和胆都有了，贼没了。」——《逐玉》赵大娘台词（2026 出圈）。
**句式拆解**（剥壳取句式，脱离原剧）：
- 三段式年龄递进：年轻（条件 A + 缺条件 B）→ 年壮（条件 B + 缺条件 A）→ 老来（条件齐了，对象/机会没了）
- 核心 = 「人生错位」：条件永远凑不齐，戳中「颜值保鲜期/时机不等人」的普遍焦虑
- 变体：年轻没钱有时间 / 中年有钱没时间 / 老了有钱有时间没人陪；或「有身体没脑子 / 有脑子没身体」
**适用场景**：颜值保鲜期话题、中年人自嘲、人生感悟段子、角色台词（市井长辈说金句）；可作配角的高光台词。
**用法示例**：「你叔那代人是这样——年轻有力气没媳妇，中年有媳妇没力气，现在条件都齐了，人也退休了，就剩在家遛弯。」

**使用情况**：待用
