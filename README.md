# 网文知识库

面向网文写作者的本地灵感资产库：**随手记 → 好检索 → 能复用**。

## 目录结构

| 编号 | 模块 | 说明 |
|------|------|------|
| 00 | 收件箱 | 碎片灵感速记区，每周整理归入正式分类 |
| 01 | 索引 | 总索引、标签索引、复盘记录 |
| 02 | 设定 | 角色 / 外挂 / 世界观 / 势力体系 |
| 03 | 开篇片段 | 钩子、节奏、亮点拆解 |
| 04 | 剧情创意 | 反转 / 伏笔 / 冲突 / 桥段 / 悬念 |
| 05 | 写作概念 | 解析类："是什么"（抽象、黄金三章等） |
| 06 | 写作技巧 | 实操类："怎么做"（打斗写法、悬念埋设等） |
| 07 | 热梗 | 出处、含义、适用场景、用法 |
| 08 | 模板 | 各分类填空模板，新建条目时复制即用 |
| 09 | 归档 | 完结作品/已用尽/过期的条目，登记台账后移入 |
| 10 | 运营 | 平台规则与连载运营（番茄规则/追读/书名简介/上架营销） |
| 11 | 同人 | 同人素材专区：方法论/机制/趋势（版权边界内提炼，2026-08-11 新增） |

## 通用骨架（所有条目共用）

```markdown
# 标题

---

正文（含分类专属字段）

**使用情况**：灵感 / 待用 / 已用
**Tags**：#题材 #类型 #状态 #格式
**来源**：（可选）出处
```

顺序约定：**正文主体在前，使用情况、Tags、来源在后**——创作内容永远优先展示。

## 标签体系（四类）

- **题材**：#玄幻 #都市 #仙侠 #科幻 #悬疑 #末世 …
- **类型**：#主角 #反派 #系统 #金手指 #伏笔 #反转 …
- **状态**：#灵感 #待用 #已用
- **格式**：#角色卡 #外挂卡 #世界观卡 #势力卡 #开篇 #剧情创意 #概念 #技巧 #热梗 #运营卡

## 命名规范

- 文件夹：`数字前缀-名称`（排序稳定）
- 条目文件：`[分类]-[名称].md`，例如 `世界观-功德法修炼体系.md`
- 速记文件：`[日期]-[关键词].md`，例如 `2026-08-09-灵光一现.md`

## 信息添加方式（四种通道）

| 通道 | 方式 | 场景 |
|------|------|------|
| 手动速记 | 一句话扔进 `00-收件箱` | 灵感闪现、随手记录 |
| AI 辅助采集 | 发链接/关键词，自动抓取并生成模板草稿，确认后入库 | 从 B站/番茄/知乎/小红书采素材（渠道见 `01-索引/采集渠道.md`，筛选标准见 `01-索引/采集标准.md`） |
| 周期简报 | 定时任务自动跑热榜，产出素材简报 | 每周批量补充 |
| 直接导入 | 复制粘贴文本/文件，按模板填空 | 已有素材入库 |

## 日常使用流程

1. **收集**：灵感一闪而过 → 扔进 `00-收件箱`（一句话即可，不打断思路）
2. **整理**：每周复盘时，把收件箱条目按模板填入正式分类并打标签
3. **消费**：写书时按 `01-索引` 或标签反查素材，用过的把使用情况改为「已用」（标注日期，防撞梗）
4. **归档**：作品完结或素材用尽 → 移入 `09-归档`（改状态为 `#已归档` + 登记台账 + 从总索引移除）
5. **维护**：每月清理过期/无效素材，更新总索引

## 复盘节奏

- 每周：收件箱 → 正式分类；更新使用状态
- 每月：清理冗余条目，检查标签一致性，更新总索引
