# 创意-伪纪录网络传说

---

**类型**：桥段（悬念 + 反转）
**设定**：虚构的「网络传说」（如 2CH 深海生物「宁根/半人半鲸」）被网民信以为真、层层加码传播，形成「伪纪录」现象——真相其实是最初的整活/创作，但谣言滚成雪球。素材超窗（2024-12），**仅取机制**。
**触发 / 回收方式**：埋点=主角在论坛刷到「目击帖」+ 配图 + 所谓专家分析；递进=up 主实地探访、民间组织跟进；回收=主角揭穿最初的发帖者（或发帖者自己都没想到会火），完成「信以为真 → 找到源头」的反转闭环。
**适用场景**：悬疑文/都市怪谈的「伪纪录」支线；主角开直播打假；网络流言题材的剧情推进引擎。
**示例**：主角的直播间被「海怪目击」流量绑架，全平台都在讨论，结果他顺着 IP 找到最初发帖的人——对方是个被深海纪录片吓到的大学生：「我随手编的，真没想火啊。」
