# 创意-怪谈保安职场流

---

**题材结构**：诡异世界里的「底层职业」职场流——主角当保安/夜班司机/便利店店员，用职业视角遭遇规则怪谈。

**可复用点**：

- **职业即视角**：保安 = 巡逻路线、交接班、门禁规则——职业规则本身就是怪谈规则的载体（交接班记录 = 上一班留下的线索）
- **底层职业 + 怪谈 = 天然反差**：越普通的工作越能遇到不普通的事，读者代入门槛低
- **与夜班司机流同频**：与《深夜钢筋》夜班司机流同构（夜间职业 + 都市怪谈 + 单元事件），可互换「职业外壳」复用结构

**触发 / 回收方式**：开篇用岗位职责引入第一个怪谈 → 每章一个「值班事件」单元 → 主线是「这岗位为什么没人敢长期干」的谜底。
