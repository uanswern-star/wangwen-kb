# 创意-规则怪谈百无禁忌

---

**设定**：SSSSS 级天赋「百无禁忌」——免疫规则污染并反将污染转化为增强；血月触发隐藏强化；破家规陷阱靠「精准解读规则 + 逆向思维夺道具」（家规说 X，就钻 X 的漏洞）。

**内核（可复用）**：规则怪谈的爽点在「**规则博弈**」——主角不是硬抗诡异，而是逐字抠规则的漏洞反向利用。天赋类可设计为「规则的敌人」（免疫/转化/改写规则）。

**触发 / 回收方式**：副本开局丢出三条规则 → 主角逐条拆解（哪些是幌子、哪些可钻）→ 利用规则反杀 → 结尾回收「规则本身有意志」的悬念。

**关联提示**：与库内「反直觉规则反转」「死亡列车无限流」互参（本卡偏怪谈设定，非关卡结构）。

**适用场景**：都市怪谈/规则流副本，《深夜钢筋》可化用「夜班司机的三条规矩」。

**使用情况**：待用
