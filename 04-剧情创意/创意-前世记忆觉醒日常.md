# 创意-前世记忆觉醒日常（剥壳取核）

---

**脑洞**：孟婆汤失效 → 全城人陆续觉醒前世记忆 → 项羽想吃霸王餐，结果饭店老板前世是嬴政的厨子、藏獒是蒙恬转世——历史名人集体转世现代，日常社交处处是社死现场。

**内核（可复用）**：历史/仙侠大人物转世现代，身份与现实的错位喜剧——「这辈子混得再差，上辈子也是个人物」的反差张力。觉醒记忆 ≠ 立刻变强，而是先面对社死与生活琐碎。

**触发 / 回收方式**：以「想占便宜 → 撞上上辈子熟人/仇人 → 当场社死」推进；大人物的小心思（项羽想吃霸王餐）与伟人身份的反差即是笑点。

**剥壳提示**：项羽/刘邦/嬴政/蒙恬为真实历史人物 → 用于原创需「三改一留」：改架空朝代名人（或纯虚构大佬），留「转世觉醒 + 日常社死」内核。

**适用场景**：都市日常喜剧、轻小说式反差人设、系统觉醒前的铺垫章节。
