# 创意-卤味店人情单元

---

**场景**：楼下一家卤味店，阿姨每次都会把主角喜欢吃的先卤好留着；主角与金毛犬、邻里之间的日常互动——「每次拿喜欢吃的东西找阿姨卤一下」的定点人情。

**内核（可复用）**：市井单元剧的「**定点人情**」结构——一个固定场景 + 一个固定熟人 + 每次去都有一句固定对白（「今天给你留了 xx」），用重复中的微变化写关系升温。烟火气 = 有温度的重复。

**触发 / 回收方式**：日常单元推进关系 → 某一集阿姨出事（店关了/人不见了）→ 主角才发现这家人情早已成了自己的锚点 → 反哺主线。

**关联提示**：与库内「概念-市井流」「早餐摊主的情报站」「热心邻居阿姨」互参（本卡是「定点人情」具体场景模板）。

**适用场景**：《深夜钢筋》夜班司机流——固定早餐摊/便利店/修车铺的人情单元。

**使用情况**：待用
