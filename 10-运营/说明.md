# 运营

本目录存放**运营与平台规则**条目（"怎么经营这本书"——平台规则、连载运营、上架营销、数据解读）。

与 05-写作概念 / 06-写作技巧 的分界：
- 05/06 回答「怎么写」：概念解析、写作手法
- 本板块回答「怎么经营」：平台机制、数据、读者关系、上架策略
- 平台验证出的"写法标准"（如番茄快节奏公式）仍归 05-写作概念 `#平台套路`，不迁入本板块

## 子分类（标签维度，不强制建子目录）

| 子分类 | 标签 | 内容 |
|--------|------|------|
| 平台规则 | `#平台规则` | 各平台官方机制与政策（番茄规则、起点规则等） |
| 连载运营 | `#连载运营` | 追读、数据解读、评论区、更新/断更策略 |
| 上架营销 | `#上架营销` | 书名简介、推荐位、榜单、粉丝运营 |

## 命名规范

`运营-名称.md`（如 `运营-番茄平台规则.md`）

## 标签规范

- 格式标签：`#运营卡`
- 状态标签：`#灵感` / `#待用` / `#已用`
- 子分类标签：`#平台规则` / `#连载运营` / `#上架营销`

## 新建条目流程

1. 复制 `08-模板/运营卡.md` 到本目录
2. 重命名为 `运营-名称.md`
3. 填空：类型 → 适用平台 → 核心规则 → 操作要点 → 示例 → 常见误区
4. 打标签（格式 + 子分类 + 状态）
5. 更新 `01-索引/总索引.md` 的 10-运营 表
