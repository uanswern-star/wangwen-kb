# 同人

同人素材专区（2026-08-11 新增）。集中存放从同人创作中提炼的**方法论 / 机制 / 趋势**素材——**不收藏同人作品本身**。

## 版权边界铁律

| ✅ 能采（机制层） | ❌ 不能采（表达层） |
|---|---|
| 同人写作方法论（为什么爽 / 如何改写 / OOC规避） | 照搬原作设定、角色二创细节、剧情 |
| 高播放同人文/视频的机制拆解（提炼观点） | 直接引用同人文段落/视频文案（转摘需授权） |
| 热门原作可借鉴点（世界观 / 角色原型 / 空白处） | 依赖现实名人的二创（吴京/沈腾等） |
| 原创化改编思路（忍界→自创体系） | 平台明令禁止的擦边内容 |

判定口诀：**"能不能写进自己下一本书"**——照搬表达不行，提炼规律可以。

## 组织方式

本区平铺存放，命名前缀保留原类型（`概念-同人XX` / `技巧-同人XX` / `创意-XX`），用标签区分类型（#概念 / #技巧 / #剧情创意）+ 主题标签 #同人。量大后可仿 `02-设定` 按类型分子目录。

## 新建条目流程

1. 采集：走 `tongren-collector` skill（渠道词库 + 版权过滤 + A/B/C 分级）
2. A 级草稿经用户确认后写入本区
3. 命名 `概念-同人XXX.md` / `技巧-同人XXX.md`，按对应模板填空（写作概念卡 / 写作技巧卡 / 剧情创意卡）
4. 打标签（含 #同人），更新 `01-索引/总索引.md` 的 11-同人 表

## 归档

同人素材过期/弃用 → 移入 `09-归档/同人/`，按归档五步执行（改使用情况 → #已归档 → 登记台账 → 从总索引移除）。
