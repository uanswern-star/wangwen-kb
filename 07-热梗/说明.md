# 热梗

本目录存放**热梗**条目（出处、含义、适用场景、用法，注意标注时效）。2026-08-13 起扩充收录范围：**搞笑梗 / 经典语录 / 生活梗 / 玩梗调侃**均可入库，目标解决「不够轻松搞笑、读者代入感弱」。

**分类方式**：按月份分子目录存放，目录命名 `2026-X月/`（如 `2026-8月/`），梗产出/爆发所在月份即其归属。`说明.md` 留在根目录。

**时间窗**：采集窗口为**近半年**内的梗/语录（2026-08-13 起执行），标注产出日期；超过半年的过气梗归档不删除。

**新建条目**：复制 `08-模板/热梗卡.md` → 放入对应月份子目录 → 重命名为 `热梗-名称.md` → 填空 → 更新 `01-索引/总索引.md`（登记月份）。

**条目类型与标注**：

| 类型 | 特征 | 标注 |
|------|------|------|
| 原创热梗 | 不依赖原 IP，可写入正式作品 | 正常标签 |
| 玩梗调侃 | 依赖原 IP 知名度（游戏/影视/名人梗），脱离原作无法复用 | `#玩梗` + 使用情况「调侃用途」，**不用于正式作品** |
| 经典语录 | 金句、高情绪浓度表达，提炼要点入库（不转摘大段原文） | 使用情况标注「语录·适用场景」 |
| 生活梗 | 贴近生活、烟火气、读者有共鸣的日常梗 | 正常标签 |
