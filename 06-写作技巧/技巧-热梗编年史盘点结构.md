# 技巧-热梗编年史盘点结构

---

**出处**：B站「热梗编年史2025年度总结」（卡洛Calo，2026-02-15，内容为 2025 年度）；「盘点互联网上的万恶之源」（刘哔Game，表情包创世神溯源）。

**核心结构（盘点类内容的通用骨架）**：
1. **分组打分**：56 位「英雄」趣味打分回顾年度抽象梗——给每个梗一个「角色位+评分」，娱乐化排序
2. **溯源链**：原型 → 二创过程 → 文化影响（表情包创世神：憨憨猫/Chimes/道子/泡泡猫→鬼畜恶搞→全球符号）
3. **跨界对比**：游戏/社会文化/经典 IP 二创混编，展示亚文化生态碰撞
4. **情绪收束**：结尾落回「玩梗文化对网络生活的影响」，给盘点一个意义锚点

**写作价值**：
- 章末预告句式：「群星璀璨时，一个没看过的也是神人了」——盘点类标题钩子
- 素材管理：年度分组盘点法——写作素材按「人物位+评分」归档，检索记忆效率高
- 番外篇/角色介绍：给配角群做「英雄打分」式群像介绍
