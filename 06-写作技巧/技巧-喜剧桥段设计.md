# 技巧-喜剧桥段设计（B站喜剧创作方法提炼）

---

**适用场景**：轻松搞笑文 / 沙雕桥段 / 配角喜剧反应 / 主角幽默吐槽 / 对话笑点

**操作要点**（源自 B站「喜剧的创作方法总结」咩咩纯牛奶，2026-08-13 提炼）：

**0. 三个前提（先想清楚再动手）**
1. 搞笑只是强化故事的手法，救不了一个本就无聊的故事
2. 积累最重要——没事就"进货"表情包和热梗（对应知识库 07-热梗）
3. 越直白越简单越容易让人看懂，看懂才可能觉得好笑

**1. 角色设定：越接地气、越不合理，越容易出笑点**
- 小人物型（史上第一混乱·萧蔷）：市井气、嘴硬、流氓气 → 自带笑点
- 不合理人物型（慎重勇者）：行为与身份严重不符
- 常见搞笑人设四款：
  - 呆瓜：一本正经做蠢事
  - 脑补怪：表面冷静，内心戏极多（迪化流基础）
  - 颠公颠婆：行为不正常 + 内心也不正常
  - 大实话：攻击性强，专治社死（说话直戳要害）

**2. 情节设计：先定对象 → 定负面特点 → 故事呈现**
- 核心：总要有"小丑/倒霉角色"（喜剧的前提——有人倒霉才好笑；悲情内核延伸）
- 两种手法：
  - **反常**：角色进入不符合他人设的场景（如铁血将军被迫带娃）
  - **错位**（三种）：
    ① 关注点错位：正常的事 + 不正常的动机
    ② 过程错位：过程全错但阴差阳错达成目的
    ③ 理解错位：两人不在一个频道却能顺畅对话（迪化）

**3. 文笔原则**
- 文字尽量口语化
- 多写心理活动变化（内心戏是吐槽流的引擎）
- 金句积累三方向：巧比喻 / 改写固定用语（替换关键词，词性不变）/ 成语接龙和押韵（天然搞笑）

**4. 搞笑八手法**（灵活使用，强用会尴尬）
1. 笑点堆积：极短篇幅堆大量梗，以量取胜（《颠都颠颠点好啊》2000 字 20+ 梗）
2. 回旋镖：首尾呼应 / Call back（脱口秀常用）
3. 打破第四面墙：直接对读者说话（死侍式）
4. 重复：同一梗反复出现强化
5. 道具反差：表面 A 实际 B（大哥大电话实为刮胡刀）
6. 夸张：越夸张越搞笑
7. 文字游戏：谐音梗（飞机是破铜烂铁→不会繁殖→菜鸡都是假的）
8. 黑色幽默：低于笑话、讽刺嘲讽

**5. 笑点密度**：常规 400 字一个笑点，极端 100 字一个梗（开头阶段梗越密越能留住读者）

**实战模板（可直接套用）**：说谎者游戏式迪化
主角是全场最弱/最怂 → 但每个懦弱行为都被误读为深谋远虑 → 其他人脑补出大佬人设 → 主角躺赢。即「一切怂行为 → 被误解为大佬操作」的喜剧引擎，适合《深夜钢筋》装逼打脸桥段。

**常见误区**：为搞笑而搞笑（脱离人物和逻辑）→ 只会尬；笑点太密没有喘息 → 读者疲劳；梗依赖原 IP → 记得标 #玩梗 只作调侃。
