# 感情线推进

---

**适用场景**：写男女主/搭档关系线；避免感情线突兀或注水。

**操作要点**：
1. 规划节点表：相识 → 心动 → 考验 → 确定 → 危机 → 升华，每 20-30 章一个感情节点
2. 三阶段推进：相识（第一印象 + 一个"不同"的瞬间）→ 羁绊（共同经历 + 为对方付出/牺牲）→ 确立（一个不可逆事件绑定关系）
3. 用工具推进：共同目标（并肩作战）、反差揭示（发现对方不为人知的一面）、患难时刻（保护与被保护）、误会与和解（误会要短、和解要有浓度）
4. 与主线并行：感情戏不能停主线，最好互为因果
5. 写专属细节：信物/暗号/共同习惯，成为读者嗑糖的记忆点

**示例**：先婚后爱节点示范：契约结婚（相识）→ 共同应对家族危机（羁绊）→ 女主病重男主彻夜照顾（心动）→ 误会分离 → 破镜重圆（确立）。

**常见误区**：一见钟情就表白（没有过程）；为发糖而发糖（工具人恋爱）；感情线挤占主线；一个误会拖几十章（读者弃书）。
