# 技巧-细纲速成法

---

**适用场景**：细纲写不动/写太满；追求「快出细纲 + 每章不空转」；与 `技巧-大纲构建进阶法`、outline-workflow「四问五段六项」细纲公式搭配。

**操作要点**：
1. **四行字细纲**（网文董卓半碗红烧肉）：细纲=章节龙骨，**4-6 句话即合格**——背景 / 危机 / 外挂觉醒 / 爽点释放。每章先定**战略目标**（锁住读者，这章凭什么留住人）vs **战术目标**（点下一章，钩子往哪指）；宏观+微观双重冲突；断章留钩子；每章一个主旨。（与「四问定骨」互相印证：背景=在哪、危机=冲突、外挂/爽点=释放）
2. **每章 20 字细纲**（大啊毛君）：大纲=整篇构架（完整主线 / 每阶段目标 / 伏笔安排，另设人物·环境·等级）；细纲**极简到每章 20 字总结**即可，不用展开写；经验：不写大纲 3 万字后必崩。
3. **细纲三法**（平欧子，按章节类型选）：延伸（顺着上一章逻辑推进）/ 拆解（把大事件拆成多章）/ 循环（重复结构但每次升级，如打脸-再打脸）。
4. **战略/战术双目标自检**：写完一条细纲，问两句——「这章读者为什么还看？」（战略）+「读者为什么想看下一章？」（战术），答不上来就重修。

**示例**（20 字 + 四行拆解）：
- 20字：宗门大比，废柴主角觉醒外挂，一招反杀夺冠。
- 四行：背景=宗门大比决赛（全场瞩目）→ 危机=对手羞辱主角+境界压制 → 外挂觉醒=签到金手指临界触发 → 爽点释放=一招反杀，全场哗然；战术目标=夺魁后惊动长老（钩子指向下一章）。

**常见误区**：细纲写成小作文（又长又不执行）；只写「发生了什么」不写「读者为什么看」（缺战略目标）；每章主旨散乱（一章塞三件事，读者记不住）；断了不接（钩子指向的下一章对不上）。
