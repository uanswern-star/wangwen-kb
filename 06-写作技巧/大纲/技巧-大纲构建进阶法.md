# 技巧-大纲构建进阶法

---

**适用场景**：大纲已入门、需要更硬核方法论；卡在「大纲写出来不落地/不好看」的进阶选手；与 `技巧-大纲设计`（基础三层法）搭配使用。

**操作要点**（多源方法按需组合）：
1. **高潮逆推法**（宝剑侍从）：从卷末大高潮倒推大纲——先定大爽点，再往前铺路；配套「计划意外构建法」：主角有计划 + 剧情给意外，两线对撞出剧情。金手指先定升级/装逼路线，再与主线大矛盾/小矛盾挂钩；人物成长线贯穿始终。
2. **大纲准备三件事**（竹子）：灵感记录 → 选脑洞 → **刷同类文（读几十本）+ 查资料** → 才动笔。三阶段：一句话核心梗（谁遭遇什么→做了什么→结局如何）→ 三百-五百简纲 → 一千-五千粗纲 → 设定落地（世界观文档 + 人物小传）。写偏靠改大纲拉回。
3. **因果线设计**（红帽子爱码字）：先定核心卖点/爽点 → 理因果线（**所有设定都是伏笔**）→ 问题-条件-解决框架 → 定字数/节点 → 感情线+事业线双线 → 期待感管理 → 章纲设计。
4. **三种大纲法**（平欧子，按卖点选一种）：以人物设定为核心 / 以故事爽点为核心（拆书）/ 以核心要素为核心。
5. **主线与支线**（大啊毛君）：主线贯穿全文、支线服务主线控制数量、伏笔衔接新支线、动态三线并进（生存/成长/冲突）——与现有「三线并行」公式互证。
6. **大纲两功能**（网文徐掌柜）：记成长轨迹防吃书 + 事件框架（反常事件/起伏）；「一事不烦二主」（一个事件只服务一个目标）；脸谱化配角降理解成本。
7. **创作流程三分离**（小作家）：想象故事 → 构建画面 → 转译文字，三步分开处理，效率远高于三者混做（细纲提前准备 = 步骤分离提速）。

**示例**：写都市复仇文——先定卷末大高潮「主角在发布会现场当众掀翻仇家集团」（逆推），往前铺：金手指=信息差/黑料搜集（升级路线=小料→大料→核弹料，与主线矛盾挂钩）；全书三线=生存线（打工藏身份）、成长线（人脉网扩张）、冲突线（与仇家集团博弈）。

**常见误区**：跳过刷同类文直接动笔（方向感全靠猜）；只做粗纲不做设定落地（人物小传缺位，角色飘）；因果线断裂（设定出现却不回收）；支线数量失控（服务主线的支线才能留）。
