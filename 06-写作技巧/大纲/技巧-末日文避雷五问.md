# 技巧-末日文避雷五问

---

**五问自查表**（写任何末世/灾变/体系文前过一遍）：

1. **囤货是否脱离现实逻辑？** 主角物资无限囤积，末日场景沦为五星级度假村 → 问问资源从哪来
2. **物资/系统生产是否违反常识？** 作者缺乏常识导致物资逻辑混乱（系统化生产、超常物资可持续）→ 有没有解释？
3. **角色黑化是否无脑单一？** 人物行为极端化，缺乏人性复杂与道德挣扎 → 见「技巧-主角塑造避雷：冷漠旁观」
4. **是否披着末日皮实际写种田修仙？** 复合题材没问题，但主体要站得住
5. **军队/官方/秩序是否突兀消失？** 末日文中政府公安军队机构集体隐身，缺乏解释 → 至少给一句交代

**战力锚点自洽**（subtitle 核对补录）：士兵机枪几百发打不死丧尸，主角一把破菜刀当场劈丧尸群、一炸一大片——「菜刀 > 巡航导弹」的失衡会让读者瞬间出戏。主角可以强，但要么给特殊规则/设定铺垫，要么让读者服气。

**通用性**：五问不止适用于末日文——任何「体系崩塌/灾变」题材都能当自查表。
