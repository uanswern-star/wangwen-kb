# 写作技巧

本目录存放**写作技巧**条目（实操类："怎么做"——打斗写法、悬念埋设等可直接上手的手法）。

## 命名规范

`技巧-名称.md`（如 `技巧-反派塑造.md`）

## 标签规范

- 格式标签：`#技巧`
- 状态标签：`#灵感` / `#待用` / `#已用`（对应「使用情况」）
- 主题标签：如 `#反派 #反转`，按需补充

## 新建条目流程

1. 复制 `08-模板/写作技巧卡.md` 到本目录
2. 重命名为 `技巧-名称.md`
3. 填空：适用场景 → 操作要点（步骤清单）→ 示例（示范片段）→ 常见误区
4. 打标签（格式 + 状态 + 主题）
5. 更新 `01-索引/总索引.md` 的 06-写作技巧 表
