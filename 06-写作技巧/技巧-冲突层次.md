# 冲突层次

---

**适用场景**：规划全书的冲突升级；避免"打怪流水账"或"闷"。

**操作要点**：
1. 三层设计：内心冲突（怕/恨/愧疚——主角与自己）、人际冲突（对手/亲友/爱人）、世界冲突（体制/命运/大环境）
2. 层次联动：内心缺陷 → 人际摩擦 → 卷入更大漩涡，三层互相喂养（一根线串起来）
3. 每卷定主冲突层次：个人 → 势力 → 世界，逐级升级，别一直停在同一层
4. 加内心代价：主角每次大动作都有"赢了但失去了什么"，避免纯爽无味
5. 同质检查：连续章节冲突同质（都是打脸/都是逃跑）就换层次

**示例**：层次联动示范：主角的懦弱（内心）→ 好友为他挡刀而死（人际）→ 他被迫卷入宗门战争（世界）——三层一根线，每层升级都有前因。

**常见误区**：只写外在冲突（打怪流水账）；只写内心冲突（闷、没爽点）；层次跳跃无铺垫（读者跟不上）；冲突永远同级别（没有升级感）。
