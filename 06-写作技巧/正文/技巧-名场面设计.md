# 名场面设计

---

**适用场景**：全书读者记住的 10% 高光场景（第一次打脸/告白/决战/身份揭晓）——决定一本书口碑的"截图点"。

**操作要点**：
1. 名场面公式：情绪蓄力（前文铺垫期待/仇恨/甜蜜）→ 临界点（差一口气）→ 爆发（蓄力兑现）→ 余韵（收尾镜头/一句台词定格）
2. 蓄力要够长：名场面的震撼度与蓄力长度成正比（憋得越久炸得越响）
3. 爆发要"超预期"：不是简单碾压，而是读者没想到的方式（打脸用阴谋而非武力，揭晓用细节而非喊话）
4. 放慢放大：名场面用特写/慢镜头写（参考"镜头感描写"概念），给足满足感，别一笔带过
5. 金句收尾：名场面最后一句要"能截图"（"三十年河东，三十年河西，莫欺少年穷"就是名场面金句）
6. 控制数量：一本书 5-8 个名场面足够，个个用在对的地方

**示例**：打脸名场面节奏：羞辱铺垫 → 沉默积蓄（主角一言不发）→ 轻描淡写反击 → 全场死寂 → 一个旁观者的震惊反应（衬托）→ 主角平静离场 + 一句金句。

**常见误区**：名场面写得和普通章节一样快（没有放慢放大）；金句硬凹（读者尬到抠脚）；每章都想做名场面（结果一个都没有）。
