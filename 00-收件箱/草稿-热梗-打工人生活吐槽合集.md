# 草稿-热梗-打工人生活吐槽合集

---

**类型**：生活梗卡（烟火气/共鸣感，服务「读者代入感弱」问题）
**适用场景**：市井配角台词 / 主角内心吐槽 / 轻松章节填充 / 都市文日常桥段
**收集时间窗**：2026-08-13（近半年网络热传段子）

**精选梗（提炼要点 + 用法）**：

**打工人自嘲系**：
1. 「上班=有钱，有钱=快乐，所以上班=快乐。」—— 反讽三连，适合装傻主角一本正经说
2. 「早八想尖叫，我开始理解公鸡了。」—— 早起场景搞笑
3. 「哪有什么寸金难买寸光阴，老板100块买我8小时。」—— 市井打工人台词
4. 「如果我们不是牛马，换公司为什么叫跳槽？」—— 巧问，配角吐槽役专用
5. 「本人体质贼弱，擅长已读不回，超过两个工作就得喘一会儿。」—— 当代打工人自嘲，适合咸鱼主角

**生活囧事系**（烟火气）：
6. 「早餐店老板问想吃什么，我说随便，老板回：我不卖随便。」—— 市井对话梗，天然场景
7. 「站上体重秤发现涨了两斤，翻出口袋掏出手机再称，数字立马正常。」—— 生活细节梗，代入感强
8. 「理发师下手没轻没重，剪完照镜子，怀疑自己换了张脸。」—— 生活共鸣
9. 「出门忘带钥匙，蹲在家门口吹风，静静思考人生。」—— 独居打工人画面感
10. 「网购被买家秀打动，到货上身直接变身接地气精神小伙。」—— 落差梗

**串烧式用法**（给《深夜钢筋》参考）：
- 何戳（电台解说）可以在解说鬼出租日常时，用「班味腌制」风格串生活梗：把主角的灵异事件用打工人视角吐槽，喜剧效果翻倍。例：「钢姐这趟活，跟早八挤地铁一样，人还没到，魂先没了。」

**为什么戳人**：全部是真实生活细节 + 自嘲口吻，读者（尤其都市打工人）能一秒对号入座。写市井气配角时，一句生活梗就能让角色活起来。
