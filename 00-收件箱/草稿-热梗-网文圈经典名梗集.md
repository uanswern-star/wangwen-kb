# 草稿-热梗-网文圈经典名梗集

---

**适用场景**：老书虫梗、章末彩蛋、同好对话、玩梗调侃（标 #玩梗 不用于正式作品主体）
**收集时间窗**：2026-08-13（B站盘点视频提炼）

**经典名梗（出处 + 含义 + 用法）**：

**五大最出名梗**：
1. **龙傲天**（网文通用）——主角与龙结缘逆天改命的人设模板，已成"装逼无敌流"代名词。用法：调侃型主角人设的靶子，或反套路解构对象。
2. **斗气化马**（《斗破苍穹》电视剧版）——原著"斗气化翼"被改成骑马，粉丝吐槽剧情魔改。用法：改编烂梗，可作作品内部自嘲（如"斗气化马，动力不足"）。
3. **辰东晚年不祥，浑身长满红毛**（《遮天》+ 辰东后期作品）——书迷怨念梗。用法：作者断更/质量下滑时的读者自嘲。
4. **我的羊去哪了**（《帝霸》李七夜）——放羊把羊弄丢的名场面。用法：呆萌系强者反差人设参考。
5. **卷毛狒狒，处处是爱**（《诡秘之主》）——读者自称卷毛狒狒。用法：粉丝向彩蛋、评论区玩梗。

**名梗十五连**（简版）：
- 「天下第一，扶墙而走」（《雪中悍刀行》）——体力不支的骚话
- 「念头通达」（《阳神》）——修行顺利/爽到，老书虫口头禅
- 「九成八」（《师兄实在太稳健了》）——稳健流主角渡劫口头禅
- 「我儿王腾有大帝之姿」（《遮天》）——捧杀句式模板
- 「复活吧，我的爱人」（《斗破苍穹》美杜莎梗）——复活流/深情反派
- 「天不生我李淳罡，剑道万古如长夜」（《雪中悍刀行》）——吹嘘句式天花板
- 「手握日月摘星辰，世间无我这般人」——装逼宣言模板
- 「有朋自远方来，虽远必诛」——错位改编（《论语》+ 汉话混搭）
- 「齐先生在吗」（《剑来》）——遇事不决喊大佬句式
- 「我的貂缠在腰上」——开车流文字游戏典范
- 「100遍啊100遍」（《神墓》紫金神龙）——复读机式威胁

**用法建议**：
- 都是"能写进自己下一本"的句式级素材：取句式骨架，换名字/换语境，就是原创台词
- 直接引原梗 → 标 #玩梗，仅作调侃/彩蛋
- 对《深夜钢筋》：何戳的电台解说天然适合"书虫梗"——吐槽时引用一句「天下第一，扶墙而走」，老书虫读者会心一笑
