# 归档区说明

存放**不再活跃**的条目。归档 ≠ 删除——保留记录，随时可回溯，只是不再出现在日常检索路径里。

## 什么该归档

| 场景 | 说明 |
|------|------|
| 作品完结 | 一本书写完，其用到的角色/外挂/世界观/创意整体归档 |
| 素材用尽 | 某条目已在正文充分使用，短期内不会再复用 |
| 热梗过期 | 时效性梗已过气（注明过期时间） |
| 长期未动 | 超过 6 个月没有更新的旧条目 |

## 组织方式（二选一，按需建子目录）

- **按作品（推荐）**：`09-归档/《书名》/`，内部保留原分类结构（角色/世界观/…），完结一本书直接拖进去
- **按分类**：`09-归档/角色/`、`09-归档/热梗/`、`09-归档/开篇片段/` …

## 归档步骤

1. 移动文件到 `09-归档/` 对应子目录
2. 使用情况改为：`已用（已归档，日期）` 或 `已归档（原因，日期）`
3. Tags 状态标签改为 `#已归档`（保留原题材/格式标签便于检索）
4. 登记到 `归档台账.md`
5. 从 `01-索引/总索引.md` 移除该条目（台账里留有完整记录）

## 已归档条目的使用情况写法示例

```markdown
**使用情况**：已归档（作品完结，2026-08-09）
**Tags**：#角色卡 #反派 #玄幻 #已归档
```
