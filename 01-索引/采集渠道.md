## 采集指令（对话式，说人话即可）

```text
采集 https://www.bilibili.com/video/BV1vtMy63E4G        → 抓取该视频，按合适分类生成条目草稿
采集 B站 搜索「网文写作技巧」                          → 搜索结果 → 选几条生成草稿
采集 番茄 搜索「赘婿」                                 → 热门书信息 → 剧情创意草稿
采集 知乎 热榜                                         → 今日热榜 → 可挖的选题提示
本周素材简报                                           → 自动跑主要渠道，产出简报放收件箱
```

## 采集入库五步（AI 辅助，确认制）

1. **给来源**：粘贴链接 / 说关键词 / 说"简报"
2. **抓取**：适配器 → API → cookies 直连（按可用性降级）
3. **提炼**：去噪 → 判断分类 → 填对应模板（草稿）
4. **确认**：你审核草稿，可修改
5. **入库**：写入对应分类目录 → 打标签 → 登记总索引（来源字段自动填：渠道 + 链接 + 日期）。热梗额外一步：放入 `07-热梗/YYYY-X月/` 对应月份子目录，总索引登记月份
