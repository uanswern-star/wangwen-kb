# 采集标准 · 信息收集规范

制定于 2026-08-09（浏览器桥已连接，B站/番茄/小红书实测可用，抖音待重试）；2026-08-11 修订：热梗按月份归档。
目的：**让入库的每一条素材都经得起复用**，避免知识库变成垃圾回收站。

---

## 一、入库门槛（三条硬标准，全过才收）

| # | 标准 | 问自己 |
|---|------|--------|
| 1 | **可复用** | 这条能用在多个场景/多本书，还是一次性笑料？ |
| 2 | **有记忆点** | 是否独特、有反差/钩子/画面感？烂大街套路不收 |
| 3 | **可落地** | 看到就能想到"用在哪"，或稍加工就能用？ |

软标准（加分项）：**来源可靠** —— 优先一手内容、高赞高播放、有出处的素材。

## 二、优先级分级（A/B/C 三档）

- **A 级 · 立即入库**：三标准全过 + 画面感强 → 直接填模板进正式分类
- **B 级 · 收件箱**：有点意思但用途未明 → 一句话速记进 `00-收件箱`，周复盘定夺
- **C 级 · 丢弃**：无记忆点 / 过气 / 来源不明 → 不采或直接删

> 经验比例参考：10 条原始信息 ≈ 3 条 B 级 ≈ 1 条 A 级。达不到这个淘汰率说明采集标准太松。

## 三、采集规范（每条必守）

1. **来源必填**：渠道 + 链接 + 日期（防撞梗、可追溯）→ 落到条目"来源"字段
2. **原文 vs 提炼**：
   - 短视频/热梗 → 存提炼要点（我的理解 + 怎么用）
   - 长文（知乎/专栏）→ 可整体转存 Markdown 到收件箱附件
3. **热梗带月份**：采集时记录产出月份，放入 `07-热梗/YYYY-X月/` 对应子目录（如 `2026-8月/`），标注时效；过期热梗归档不删除
4. **去重检查**：入库前用关键词/标签搜一遍知识库，重复不收
5. **版权边界**：原文转摘保留来源标注；重写提炼不受限

## 四、渠道关注点（各渠道采什么、额外门槛）

| 渠道 | 关注什么 | 额外门槛 |
|------|----------|----------|
| B站 | UP主方法论（AI总结）、评论区热梗、热门设定 | 播放量高 / 评论有梗 / 观点可转写作方法 |
| 番茄 | 热门书名、简介钩子、题材风向 | 榜单前排、简介 1 句话能勾人 |
| 知乎 | 方法论长文、具体问题的可落地解法 | 高赞回答、观点可操作 |
| 小红书 | 人设、文案金句、情绪表达 | 点赞高、有画面感、能挪进小说场景 |
| 抖音 | 短剧套路、热梗、爆款开头 | 当下正热、能转化为文字情节 |
| 微博/豆瓣/贴吧等 | 热梗、社会情绪、书评观点 | 出圈讨论度、可提炼为素材 |

## 五、处理流水线（一次采集走完）

```
原始信息 → ① 过门槛（三标准）→ ② 分级 A/B/C
   → A：填模板 → 打标签 → 登记总索引
      （热梗：放入 07-热梗/YYYY-X月/ 对应月份子目录，登记月份）
   → B：一句话进收件箱 → 周复盘再定
   → C：丢弃
```

## 六、量化复盘（周简报自带）

每周简报末尾统计：采集 N 条 → 入库 A 条 → 淘汰率 X%。
连续两周入库率过低（<10%）→ 提高门槛；过高（>50%）→ 可能采太少了，扩大渠道。
