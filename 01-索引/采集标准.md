# 采集标准 · 信息收集规范

制定于 2026-08-09（浏览器桥已连接，B站/番茄/小红书实测可用，抖音待重试）；2026-08-11 修订：热梗按月份归档；2026-08-13 修订：领域禁采清单 + 同人分流 + 素材方向扩大（梗/语录/生活素材）+ 时间窗扩至近半年。
目的：**让入库的每一条素材都经得起复用**，避免知识库变成垃圾回收站。

---

## 〇、领域禁采（最高优先级，先于一切判定）

**影视、体育、军事、政治、娱乐圈 → 直接禁采**，不进入后续分级。原因：政治属敏感红线；影视/娱乐圈版权+现实名人双风险；体育/军事与当前写作赛道无关。

**方法论豁免**：若素材内容明确指向「写作方法/技巧/拆解」（如「军事文写作技巧」「从影视学大场面叙事」），即使标题含禁采领域关键词，也放行归入写作类（06-写作技巧 / 05-写作概念）。

**判定优先级**：① 政治 → 任何情况下禁采（无例外）→ ② 同人相关 → 走同人分流（见第六章）→ ③ 领域禁采 → 只对领域表达层生效。

## 一、入库门槛（三条硬标准，全过才收）

| # | 标准 | 问自己 |
|---|------|--------|
| 1 | **可复用** | 这条能用在多个场景/多本书，还是一次性笑料？ |
| 2 | **有记忆点** | 是否独特、有反差/钩子/画面感？烂大街套路不收 |
| 3 | **可落地** | 看到就能想到"用在哪"，或稍加工就能用？ |

软标准（加分项）：**来源可靠** —— 优先一手内容、高赞高播放、有出处的素材。

## 二、优先级分级（A/B/C 三档）

- **A 级 · 立即入库**：三标准全过 + 画面感强 → 直接填模板进正式分类
- **B 级 · 收件箱**：有点意思但用途未明 → 一句话速记进 `00-收件箱`，周复盘定夺
- **C 级 · 丢弃**：无记忆点 / 过气 / 来源不明 → 不采或直接删

> 经验比例参考：10 条原始信息 ≈ 3 条 B 级 ≈ 1 条 A 级。达不到这个淘汰率说明采集标准太松。

## 三、采集规范（每条必守）

1. **来源必填**：渠道 + 链接 + 日期（防撞梗、可追溯）→ 落到条目"来源"字段
2. **原文 vs 提炼**：
   - 短视频/热梗 → 存提炼要点（我的理解 + 怎么用）
   - 长文（知乎/专栏）→ 可整体转存 Markdown 到收件箱附件
3. **时间窗：近半年**（2026-08-13 起）：热梗/语录/生活素材采集窗口从「当月」扩大到**近半年内**，标注产出日期；超过半年的梗归档不删除
4. **去重检查**：入库前用关键词/标签搜一遍知识库，重复不收
5. **版权边界**：原文转摘保留来源标注；重写提炼不受限；同人素材走第六章分流

## 四、渠道关注点（各渠道采什么、额外门槛）

| 渠道 | 关注什么 | 额外门槛 |
|------|----------|----------|
| B站 | UP主方法论（AI总结）、评论区热梗、热门设定、沙雕/搞笑向视频 | 播放量高 / 评论有梗 / 观点可转写作方法 |
| 番茄 | 热门书名、简介钩子、题材风向 | 榜单前排、简介 1 句话能勾人 |
| 知乎 | 方法论长文、具体问题的可落地解法、高赞金句 | 高赞回答、观点可操作 |
| 小红书 | 人设、文案金句、情绪表达、生活细节 | 点赞高、有画面感、能挪进小说场景 |
| 抖音 | 短剧套路、热梗、爆款开头、搞笑段子 | 当下正热、能转化为文字情节 |
| 微博/豆瓣/贴吧等 | 热梗、社会情绪、书评观点、神评论 | 出圈讨论度、可提炼为素材 |

## 五、素材方向（2026-08-13 起重点补充）

**目标：解决「不够轻松搞笑、读者代入感弱」两大问题**。采集时优先照顾以下三类素材，数量上允许适当放宽（B 级可多收，周复盘时再筛）：

| 方向 | 采什么 | 例子 | 去向 |
|------|--------|------|------|
| 轻松搞笑 | 搞笑梗、沙雕剧情、反差笑点、幽默对话 | 玩梗视频、沙雕段子、综艺笑点 | 07-热梗 / 04-剧情创意 |
| 贴近生活 | 生活细节、烟火气场景、读者能共鸣的日常 | 评论区生活吐槽、真实经历片段 | 04-剧情创意 / 02-设定 |
| 经典语录 | 金句、名场面台词、高情绪浓度表达 | 高赞回答金句、影视台词（提炼改写） | 05-写作概念 / 07-热梗 |

**经典语录专项**：入库格式为「语录原文（提炼）+ 适用场景 + 为什么戳人」，不转摘大段原文，只存金句要点。

## 六、同人分流（2026-08-13 起生效）

同人相关内容不再默认 C 级，按用途三出路分流：

| 出路 | 去向 | 要求 |
|------|------|------|
| 同人写作 | 11-同人 | 只采机制/方法论/趋势，不采作品本身 |
| 非同人写作 | 主库（02/04/05/06） | **必须过"三改一留"**：改名 → 改关系网 → 改招牌（技能/口头禅/造型）→ 留内核，来源标注原 IP |
| 玩梗调侃 | 07-热梗 | 标注 `#玩梗` + 使用情况「调侃用途」，不用于正式作品 |

**判定优先级**：同人相关先于领域禁采判定（军事题材同人机制 → 按同人规则采，不进领域禁采）。

**同人特例口子**：当正在写某作品同人时，可把原作 + 高播放同人文作为**个人参考素材**放收件箱（标注「个人参考·不发布·不商用」），用完即清或归档，不进总索引、不打正式标签。

## 七、处理流水线（一次采集走完）

```
原始信息 → ① 过门槛（三标准）→ ② 分级 A/B/C
   → A：填模板 → 打标签 → 登记总索引
      （热梗：放入 07-热梗/YYYY-X月/ 对应月份子目录，登记月份）
   → B：一句话进收件箱 → 周复盘再定
   → C：丢弃
```

## 八、量化复盘（周简报自带）

每周简报末尾统计：采集 N 条 → 入库 A 条 → 淘汰率 X%。
连续两周入库率过低（<10%）→ 提高门槛；过高（>50%）→ 可能采太少了，扩大渠道。
