# 素材消费 SOP · 把素材写进正文（缺口 13 落地，2026-08-13）

> 背景：库内 194 条素材长期「灵感 190+ / 已用 ≈0」，素材与写作割裂。本 SOP 让每次写作强制消费库内素材，把知识库变成创作弹药库而非收藏夹。

---

## 一、写作前查素材（动笔前 30 秒，三查）

每写一卷/一单元前，按「开篇 → 角色 → 创意」三查一遍库，把可用的素材拉进本章计划：

```bash
python "C:/Users/Administrator/.workbuddy/kb-tools/indexer.py" --search "<关键词1>"
python "C:/Users/Administrator/.workbuddy/kb-tools/indexer.py" --search "<关键词2>"
```

- **开篇查**：写开头/卷首 → 搜「开篇」「钩子」「黄金三章」→ 03/05 的开篇卡挑结构
- **角色查**：新配角出场 → 搜「角色」「市井」「配角」→ 02-设定/角色 挑模板卡
- **创意查**：卡剧情 → 搜「创意」「桥段」「反转」→ 04 创意卡挑桥段
- **词条查**：找梗/金句 → 搜「热梗」「吐槽」→ 07 热梗卡（先搜再写，防撞梗）

示例：写《深夜钢筋》夜班单元 → `--search 夜班` + `--search 市井` + `--search 鬼`，命中 `概念-市井流`、`创意-夜班出租单元剧`、`外挂-夜班体质`、`角色-话痨司机` 直接取用。

## 二、每章用素材随手登记（写完 1 分钟）

用完一条素材立刻更新该条目「使用情况」字段（双轨制：frontmatter status + 正文使用情况行同步改）：

| 状态 | 含义 | 写法 |
|---|---|---|
| 灵感 | 未用 | 保持 |
| 待用 | 计划用 | 保持 |
| 已用 | 用进正文 | `已用（《书名》第 N 章，2026-08-XX）` |

```bash
# 改完使用情况后同步 frontmatter status 并刷新索引（改库两步走）
python "C:/Users/Administrator/.workbuddy/kb-tools/indexer.py" --build
python "C:/Users/Administrator/.workbuddy/kb-tools/indexer.py" --refresh-index
```

## 三、周复盘素材消费率（每周复盘记录必带指标）

在 `01-索引/复盘记录.md` 周复盘里统计：

```
素材消费率 = 本周新增「已用」条目数 / 本周写作用到的库内素材数
```

- 写作时完全没查库 → 消费率 0，警示：库白建了
- 用了但没登记 → 已用条数虚低，警示：登记纪律没养成
- 目标：连续两周消费率 <30% → 检查是素材不对口还是 SOP 没执行

## 四、兜底规则

- **查重在前**：任何新素材入库前 `indexer.py --search` 查重（对照 `01-索引/采集标准.md`）
- **素材过期**：热梗写不进去就归档不删除（对照 09-归档 流程）
- **快速找素材**：让 AI 按方向检索（"给我找 3 条适合写夜市摊主冲突的桥段"）→ 按结果用
